# additional — 后续需求

本目录用于保存 `bag` 插件在 `v0.1.0` 之后的追加需求、设计草案和验收说明。

## 约定

- 每个需求一个文件，建议命名：`YYYY-MM-DD-主题.md`。
- 保留需求原文、背景、期望行为和验收条件；不要只写结论。
- `v0.1.0` 的行为以项目根 `README.md`、`docs/implementation-plan.md` 和 Git 标签 `v0.1.0` 为准。
- 新需求不应直接改写已发布版本的历史说明；需要变更现有行为时，在需求文档中明确写出兼容性影响。
- 涉及数据格式、权限、CraftEngine 物品或配置结构变化时，必须说明迁移和回滚方式。
- 不在本目录记录 RCON 密码、令牌、代理凭据或其他秘密。

## 当前基线

- 版本：`v0.1.0`
- 范围：原生物品栏存储行限制、三档背包、锁定槽位占位、降级掉落、命令与配置。
- 尚未包含：CraftEngine 模型/物品适配、正式包名替换、远程仓库与 CI。
